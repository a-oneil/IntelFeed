# Contributing

Thanks for taking a look. Bug reports, fixes and ideas are all welcome.

## Support

IntelFeed is maintained in spare time, on a best-effort basis. Issues and pull requests are read and
answered when there is time. There is no guaranteed response time and no paid support.

## Reporting a bug or asking for a feature

Open an [issue](../../issues/new/choose) and pick a template. For a bug, say what you expected, what
happened, and which commit you are running.

**Security problems go somewhere else.** Don't open a public issue. See [security.md](security.md).

## Sending a change

1. For anything bigger than a small fix, open an issue first to agree on the approach.
2. Set up a local stack and run the checks: [docs/contributing.md](docs/contributing.md) has the steps.
3. Open a pull request. The template lists the checks to tick.

By sending a change you agree it is licensed under the project's [AGPL-3.0](LICENSE) license.
